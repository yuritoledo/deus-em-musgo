# Exemplo de Sessão 3 — Investigação e Diálogo

> Sessão de cidade/NPCs — sem combate. Foco em diálogo, oráculo, facções,
> tomada de decisão e consequência política.
> Personagem: druida nível 1.

---

```
═══════════════════════════════════════════
SESSÃO 22 — 3º Dia de Sol (colheita)
═══════════════════════════════════════════

─── Druida nível 1 ───
SAB +2 · DEX 0 · STR +1 · PV 6
Forma animal: lobo (d4)
Magias: Conjurar Raízes, Gust

MISSÃO
Descobrir quem está queimando os campos
leste do Mosteiro — antes que os Devotos
do Verde declarem guerra
Destino: Tênue (a 2 horas)

RECURSOS
♦ HP 6/6   Corr 0
♦ Ervas 4   Água 2
♦ Foco: Cajado de Raiz

PREPARAÇÃO
// missão diplomática — não posso chegar
//   batendo. Preciso de provas.
// levar: incenso da Chama (presente pros
//   Devotos, se precisar)
// dúvida: falo com os Devotos primeiro
//   ou vou pros campos queimados?

═══════════════════════════════════════════
DIÁRIO
═══════════════════════════════════════════

═══ CAMPOS QUEIMADOS ═══

! Saio cedo. Nos campos leste, o cheiro
  de queimado ainda está no ar. Uma faixa
  de terra preta corta o plantio de
  visgo e raiz — sagrado pros Devotos.

> Examino a borda da queimadura. Procuro
  vestígio de quem passou.

d: SAB CD 10 (sobrevivência) → 13 ✅

! Pegadas: botas com sola quadrada — não
  são de camponês (eles andam descalços
  ou de tamanco). Duas pessoas. Uma parou
  aqui, a outra foi mais fundo.

? As pegadas voltam pro Mosteiro?
  4 → Sim, mas... somem no leito do riacho
  seco. Quem fez isso tentou esconder o
  rastro.

> Sigo o riacho seco. Se tentaram esconder,
  tão perto.

═══ ENCONTRO — Margem do Riacho ═══

! No meio do leito seco, um vulto sentado
  numa pedra. Capuz marrom, cajado. Não
  se mexe com a sua aproximação.

? Reconheço a pessoa?
  5 → Sim. É a Irmã Claro — uma das
  noviças do Mosteiro. Ela saiu da ordem
  faz uns meses. Quieta, quase invisível.

" Claro. Faz tempo.

" (Claro) ...Iaô. Sabia que viria.
  Alguém tinha que vir.

> Pergunto na lata: "Foi você?"

" (Claro) Foi. Mas não é o que parece.

" Explica então, antes que eu tire
  conclusão errada.

! Ela hesita. O cajado aperta na mão.

d: CAR CD 12 (convencer ela a falar) → 10 ❌

" (Claro) Não dá. Você é do Mosteiro.
  Vai contar tudo.

> Não vou contar nada sem saber o
  contexto. "Se eu quisesse briga,
  tinha trazido o Prior."

d: CAR CD 12 (segunda tentativa) → 16 ✅

! Ela ri sem graça. Solta o cajado.

" (Claro) Os Devotos tavam plantando
  nas nossas áreas. O Prior mandou
  avisar três vezes. Eles ignoraram.
  Então... o Prior mandou um recado
  mais claro.

// OU SEJA: o Prior SABE e mandou
//   ela queimar os campos.
// isso muda tudo — não é sabotagem
//   externa, é conflito interno
//   entre Mosteiro e Devotos

? Claro tá falando a verdade?
  5 → Sim. Ela acredita que o Prior
  autorizou. Mas...

" (Claro) Só que eu vi o Prior
  ontem no jardim. Ele tava falando
  com um dos Emissários do Sol.
  De noite. Não era encontro de
  rotina.

! Ela baixa a voz.

" (Claro) Acho que o Prior não quer
  só "avisar". Acho que ele quer
  guerra. E eu fui o palito de
  fósforo.

═══ DECISÃO ═══

// puta merda. Se o Prior tá mancomunado
//   com Emissários, isso é muito maior
//   que briga de vizinhança.
// opções:
//   1. Voltar pro Mosteiro e confrontar
//      o Prior (perigoso — se for verdade,
//      ele pode me silenciar)
//   2. Ir pros Devotos com a história
//      (queimo ponte com o Mosteiro)
//   3. Investigar mais — provas antes
//      de decidir

> Vou com a 3. Peço pra Claro ficar
  aqui e vou falar com os Devotos
  sozinho. "Se eu não voltar até
  anoitecer, você conta tudo pro
  Conselho do Mosteiro."

" (Claro) Você confia em mim?

> "Você queimou campo alheio por
  ordem. Mas tá me contando a
  verdade. Confio mais agora do
  que antes."

═══ ACAMPAMENTO DOS DEVOTOS ═══

! A aldeia dos Devotos do Verde fica
  a 15 minutos rio acima. Palhoças
  entre as árvores. Eles tão em
  assembleia — dá pra ver da entrada.

? Deixam eu entrar de boa?
  3 → Não, mas... um grupo me cerca
  antes do portão. Arcos armados.

" (Devoto 1) O que o Mosteiro quer
  agora? Veio ver o estrago?

> Venho falar, não brigar. "Quero
  saber o que vocês plantaram na
  área leste."

" (Devoto 1) Plantação de visgo
  sagrado. Nosso. Em terra nossa.
  O Mosteiro não tem jurisdição
  do lado de cá do riacho.

! O grupo tense. Mãos nos cabos.

d: CAR CD 10 (acalmar) → 8 ❌

! Eles notaram minha hesitação.

" (Devoto 1) Você sabe de algo.
  Quem queimou?

? Minto ou falo a verdade?
  6 → Falo a verdade (oráculo pra decidir)

> "Foi uma noviça do Mosteiro. Mas
  ela agiu sob ordem do Prior — e
  eu acho que o Prior tá sendo
  manipulado pelos Emissários do
  Sol. Não é guerra entre nós.
  É eles."

! Silêncio. Os arcos baixam um pouco.

" (Devoto 1) ...Prova.

// tenho a palavra da Claro, mas é
//   minha contra a do Prior
// tenho o emblema dos Emissários
//   que achei na sessão 17? não —
//   foi na Torre, não na colheita

? Tem algo nos campos queimados que
  prove a manipulação?
  5 → Sim. Os Devotos encontraram
  um selo de cera no meio das cinzas
  — não é do Mosteiro, nem dos Devotos.

" (Devoto 1) Achamos isso hoje cedo
  entre as cinzas. Selo de cera preta.
  Não reconhecemos.

// selo preto = Emissários do Sol?
//   ou Capuz Vermelho?

> Pergunto se posso ver o selo.

! Um dos Devotos traz. É pequeno,
  circular, com um símbolo de SOL
  RACHADO. Emissários.

" Isso é dos Emissários do Sol.
  Eles tão plantando provocações
  entre nós. Queimaram vocês e
  colocaram a culpa no Mosteiro.
  A noviça foi só instrumento.

═══ RESOLUÇÃO ═══

" (Devoto 1) Se é verdade, a
  guerra que a gente tava se
  preparando não é contra vocês.
  É contra quem quer ver nós
  dois sangrando.

> É. E o Prior pode estar do lado
  deles — ou sendo enganado também.
  "Me dá uma semana. Vou descobrir
  onde o Prior se encontra com os
  Emissários e o que tão tramando.
  Enquanto isso, não ataquem o
  Mosteiro."

" (Devoto 1) Uma semana. Depois
  disso, a gente resolve do nosso
  jeito.

═══ RETORNO ═══

! Volto pro riacho. Claro ainda tá
  lá. Explico o plano.

" (Claro) Você enrolou os Devotos
  e não entregou o Prior. Se ele
  descobre que você sabe, você
  tá morto.

> Então a gente descobre primeiro.
  Onde o Prior se encontra com
  os Emissários?

// gancho pra próxima sessão:
//   seguir o Prior, descobrir o
//   encontro, provar a trama

═══════════════════════════════════════════
PÓS-SESSÃO
═══════════════════════════════════════════

♦ Recursos intactos (não entrei em combate)
♦ Corr 0

XP +100 (investigação + diálogo + evitar guerra)
// missão principal avançou — agora sei que
//   o Prior tá envolvido com Emissários
//   e que os Devotos tão com um pé atrás

Novos contatos:
- Claro (noviça exilada) — deve favor
- Devotos do Verde — trégua de 1 semana
- Prior — não sabe que eu sei (por enquanto)

// facções:
//   Mosteiro da Chama: +0 (tô contra o
//     Prior, mas a ordem pode me apoiar?
//     preciso de aliado dentro)
//   Devotos do Verde: +2 (evitei guerra)
//   Emissários do Sol: -3 (se descobrirem)
//   Capuz Vermelho: 0 (neutro, mas selo
//     preto me lembrou eles — investigar?)

// próxima: seguir o Prior. Preparar
//   furtividade. Levar prova definitiva.
```
