# 🎲 Oráculo Solo

Oráculo d6 para jogar solo em Deus em Musgo. Use quando precisar de uma resposta ou rumo.

## O Oráculo Básico (pergunta sim/não)

Role **1d6**:

| d6 | Resposta |
|:--:|:---------|
| 1  | Não, e... (falha + complicação) |
| 2  | Não |
| 3  | Não, mas... (falha suavizada) |
| 4  | Sim, mas... (sucesso com custo) |
| 5  | Sim |
| 6  | Sim, e... (sucesso + vantagem) |

## O Oráculo de Ação + Tema

Role **2d6** para criar um rumo ou evento inesperado:

**d6 - Ação:**
1. Avançar / Atacar / Prosseguir
2. Recuar / Proteger / Esperar
3. Revelar / Comunicar / Perguntar
4. Corromper / Infectar / Dissolver
5. Florescer / Crescer / Expandir
6. Consumir / Devorar / Silenciar

**d6 - Tema (específico do cenário):**
1. Vento / Podridão / Cheiro
2. Musgo / Esporo / Raiz
3. Memória / Visão / Sussurro
4. Fogo / Chama / Purificação
5. Osso / Carapaça / Apodrecido
6. O Deus / O Vazio / O Pulso

*Exemplo: rolei 3 (Revelar) + 2 (Musgo/Esporo/Raiz) → algo relacionado a esporos se revela. Talvez uma passagem antes oculta, talvez um segredo que os esporos estavam escondendo.*

## Modificadores

Situações mudam o dado base:

- **Favorável:** role 2d6, fique com o maior
- **Desfavorável:** role 2d6, fique com o menor
- **Muito favorável:** resposta sobe um nível (não → não mas, sim mas → sim, etc.)
- **Muito desfavorável:** resposta desce um nível
